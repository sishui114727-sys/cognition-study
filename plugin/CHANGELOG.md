# 更新记录

## 0.3.1 — 2026-10-31

修一个真实对话里露出来的毛病：读手账时拿不到引用稿件的标题和链接。测试 97 → 98 条。

### 修复：`study_journal_get` 补 `refs`

实测（2026-10-31 23:54，主人问"上次那个讲意义的视频"）：她调了
`study_list` → `study_search` → `study_note_list` → `study_journal_get`，
答对了标题、四个支柱、以及"字幕没取全"这个更正，但最后一句是
"要翻原视频我把BV给你"——**BV 没给出来**。原因是手账里只有 `readingIds`
（`r:BVxxxx:1:hash`），没有 BV 号也没有标题，她想给链接就得再调一次工具。

现在 `study_journal_get` 会顺手把引用的稿件解析成：

```json
"refs": [{ "id": "r:BVxxx:1:abc", "title": "…", "url": "https://www.bilibili.com/video/BVxxx", "coverage": "full", "fetchedAt": "…" }]
```

稿件没了的引用标 `missing: true`，不让一处缺数据把整次读取弄失败。

## 0.3.0 — 2026-10-31

让"发个链接她就开始学"成为可选能力；发布社区版安装包与发布声明。测试 74 → 97 条。

### 新增：主人发链接时提示学习（`learnOnLink`，默认关）

- 唯一的钩子 `before-llm-messages`：主人私聊里出现 B站 链接（完整链接 / 手机链接 / 带 `?p=N` / 裸 BV 号）时，
  在消息尾部追加一行提示。
- 提示内容：BV 号、是否已取过稿（已取过直接给稿件 id）、下一步该调哪个工具、没配 SESSDATA 时明说只能读简介。
- **钩子里不下载**：宿主给钩子 5 秒，取稿要打三四个请求，超时会被整轮跳过还会卡住对话。
  所以钩子只做本地能做完的事（认链接 + 查本地稿件），取稿交给工具。
- 只在 `private:<主人QQ>` 生效：群聊、别人的私聊一律不触发。
- 默认关闭：装了不会静默改变任何一轮对话。
- 注入形态遵守宿主护栏：追加到最后一条 user 消息尾部，不碰 system、不 push 新消息。

### 新增：社区版安装包

- `cognition-study-<version>-community.zip`：`plugin/`（插件本体）+ `docs/` + `README` + `INSTALL`，
  和认知核心的社区包同一种摆法。
- `INSTALL.md`：安装四步、SESSDATA 获取、首次使用、卸载、六条常见问题对照表。

### 新增：发布声明 `docs/发布说明-0.3.0.md`

- 手账现在能做什么（写 / 看 / 改 / 导 / 修 + 三条不变量）
- 怎么用（三步）
- 让大肥鱼学习主人发来的 B站 视频（含边界：只认主人私聊、只在有链接时、默认关）
- 与记忆核心的关系：两个独立插件、分工表、零代码耦合（核心提到 study 0 次）
- 可能的冲突：B站 能力重叠、上下文开销叠加、手账不被核心索引、内容可能记两遍
- 对大肥鱼的影响：更"读过"、记性有出处、有节制、不越权、可自查、不装也活着
- 实测数据与已知边界（含"真实私聊未实测"）

### 修正：重复取稿时"A I 字幕一次只给一部分"

- 实测同一视频多次取稿，段数见过 9 / 260 / 416 / 1476 段；其中 1476 段 / 16571 字那次
  折合 1300 字/分钟（12 分钟视频），正常口播到不了——是异常返回，不是"更全"。
- 原来一律"保留首份"：若首份恰好只下到 9 段，就永远只有 9 段。
- 现在有升级路径：新内容 ≥1.5 倍且 ≥200 字、并且语速 ≤600 字/分钟时覆盖；
  首份本身不可信（异常大）时，允许换成可信的更短版本。id 保持不变，手账引用不断。

### 改动

- `ReadingStore.findByBvid`：按 bvid + 分P 找最近一次取稿，钩子用它判断"是不是已经读过"。
- 测试从 74 条增到 97 条：链接识别 8 条、钩子 8 条（含群聊/别人私聊/关闭开关/重复注入/多模态消息）、取稿升级 7 条。

## 0.2.0 — 2026-10-31

手账补全：从"能写能读"到"能看、能改、能导、能修"。工具 10 → 16，测试 74 条。

### 手账新增

- **列表** `study_journal_list`：倒序、不带正文，可按 `day` 或 `from`/`to` 筛，支持分页；
  每条带「有几条修订 / 最新标题」。
- **读一篇** `study_journal_get`：原条目 + 全部修订（按时间正序），能看到"当时怎么写的"。
- **修订** `study_journal_amend`：追加新条目并指向原 id，旧条目一个字不动。
  修订不占额度；修订一条修订会被拒绝（防止链式套娃）；指向不存在的 id 直接拒收。
- **统计** `study_journal_stats`：总篇数、修订数、连续天数（今天没写则从昨天算）、
  本周、平均字数、覆盖率分布、失效引用数、今日额度。
- **导出** `study_journal_export`：按天分组写成一份 Markdown，修订以引用块跟在原条目下，
  落 `data/exports/journal-<时间戳>.md`，不覆盖旧文件。
- **修复** `study_journal_repair`：校验 → 重建派生（索引/分卷）→ 再校验，如实报告，
  账本永远不动。

### 手账加固

- 第二道额度闸：**每天 6000 字**（`maxJournalCharsPerDay`）。原来只有"2 篇"，
  两篇各八千字也能写进来。
- 引用完整性：手账引用不存在的稿件 id 时**照样写成功**，但把 id 记进 `missingRefs`，
  面板与统计都会显示；不静默删引用。
- 孤儿修订：`verify` 增加一条检查——修订指向的原条目必须存在，否则报错。
- 读卷分页：默认 6000 字/页，返回 `nextOffset`；读到底才给 `nextVolume`，
  "下一页"和"下一卷"分开，避免漏读半卷。

### 面板

- 新增两张卡：连续写作天数、今日字数；校验区补一行「修订 N 条 · N 篇引用失效 · 最近一篇」。
- 没有修订也没有失效引用时显示「还没有修订，也没有失效引用」，不显示空白。

### 修正

- `node --test test/` 在 Windows + Node 24 上会把目录当测试文件跑，直接报错。
  改为 `scripts/test.mjs` 显式枚举文件，`npm test` 两端一致。
- 打包扫描规则把 build 脚本自己扫出来了（脚本里那串 QQ 号命中了"真实 QQ 号"规则）。
  改成运行时拼接，规则不再自指。
- 沙箱复跑缺 `scripts/` 目录导致找不到测试入口；发布清单补上。

## 0.1.0 — 2026-10-31

首个可用版本。独立插件，与 cognition-core 无耦合（不 import、不共享数据、独立开关）。

### 取稿

- `study_fetch`：BV 号 / 链接 / 分P → 标题、UP、时长、简介、字幕正文。
- 字幕解析支持 B站 JSON 字幕与 WebVTT 两种格式。
- **实测**：匿名请求 16 个样本 0 命中（字幕对象被裁到只剩 `allow_submit=false`）；
  带 SESSDATA 后同一批样本立刻拿到 `ai-zh`（AI 字幕）。
- 没有字幕时标 `coverage: metadata-only`，简报第一行写明"只有标题与简介，没有读到正文"，不伪造要点。
- 命中限流（有登录态却返回空列表）时自动重试一次，并把原因标成 `NONE_MAYBE_THROTTLED`，不把限流当"这视频没字幕"。

### 简报

- 时间轴要点：按时间窗切段，每段取"信息最密"的一句（不同词数优先，长度封顶），不是最长的一坨。
- 真实 AI 字幕没有标点，专门做了按空格聚句：15–70 字一段，避免要点变成 200 字的长串。
- 高频词（中文 bigram + 英文词，过滤"啊啊"这类同字重复）、数字与术语抽取。

### 手账

- 账本 `ledger.jsonl` append-only，是唯一真相；`index.json` 与 `volumes/v-*.md` 是派生数据，可删可重建。
- 三条不变量每次读取都校验：索引 total == 账本条数、各卷之和 == total、每个 id 恰好出现一次。
- 分卷按 24KB / 350 行切；单篇超长按段落切段并标 `（续 k/n）`。
- 快照机制：读卷必须带当前快照，过期抛 `STALE_SNAPSHOT`，宁可多调一次工具也不脏读。
- 额度按账本统计（不读计数文件），重启/崩溃不重置；同内容重复提交幂等，不吃额度。

### 札记与检索

- `study_note_write`：≤600 字，必须带标签或稿件 id，否则拒收。
- `study_search`：BM25（中文 bigram + 英文词），范围可限定稿件 / 手账 / 札记；无命中返回空数组。

### 面板与配置

- 只读面板：稿件、今日取稿、手账额度、札记、校验状态、最近动作；读不到快照时明说读不到，不显示 0。
- 默认关闭；未绑定主人时所有工具拒绝执行。

### 工程

- `scripts/test.mjs`：显式枚举测试文件（Node 24 在 Windows 上把目录参数当成测试文件跑）。
- `scripts/build-dist.mjs`：跑测试 → 沙箱复跑 → 扫描本机路径/QQ号/SESSDATA/乱码 → 打 zip → 写 manifest（含 sha256）。

### 已知缺口

- 无 ASR：匿名可下载音频，但转写要几百 MB 模型，不该塞进插件。
- 无自动摘要/自动提问：没有 LLM，产出会是废话。
- 一次取一个 P：合集要逐个取。
- 手账正文不可原地编辑：要改就写修订（0.2.0 起），这是设计不是缺口。
- AI 字幕正文每次可能不同（B站端生成/分段返回不一致），重复取稿保留首份，不覆盖。
- 面板仅逻辑层验证（74 条测试里 7 条覆盖渲染）；当前模型读不了图，视觉未验收。
