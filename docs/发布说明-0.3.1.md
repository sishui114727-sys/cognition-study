# cognition-study 0.3.1 — 学习管线首发

QQ Agent 的**可选插件**：把 B 站视频的字幕取成稿子，整理成带时间轴的简报，写成每日限量的手账，再记几条带标签的札记，随时能检索回来。独立开关、独立数据、默认关闭，不并入认知核心。

```text
B站视频 → 取稿 → 简报（时间轴要点）→ 手账（每天 2 篇）→ 札记 → 检索
```

## 这一版修了什么

真实对话里露出来的毛病：她读手账时只拿到 `readingIds`（`r:BVxxx:1:hash`），没有标题和链接，于是说了句「要翻原视频我把BV给你」，**BV 没给出来**。

`study_journal_get` 现在顺手把引用解析成 `refs`：id、标题、链接、覆盖度、取稿时间。稿件没了的引用标 `missing: true`，一处缺数据不让整次读取失败。

## 十六个工具，全部 owner-only

```text
取稿    study_fetch / study_list / study_read
手账    study_journal_write / study_journal_list / study_journal_get
        study_journal_amend / study_journal_stats

        study_journal_repair
```

## 三条不变量

1. `journal/ledger.jsonl` 是唯一真相，只追加；索引、卷、面板全是派生物
2. 修订是追加，不是覆盖：改了也看得到「当时怎么写的」
3. 派生物坏了只重建，绝不倒过来改账本

## SESSDATA 是拿到正文的唯一路径

| | 有 | 没有 |
|---|---|---|
| 标题、UP、时长、分P、简介 | ✅ | ✅ |
| 字幕正文（CC / AI 字幕） | ✅ | ❌ |
| 时间轴要点、高频词 | ✅ | 只从简介抽 |
| 手账、札记、检索 | ✅ | ✅ |

没有字幕时稿件标 `coverage: metadata-only`，简报第一行就写「只有标题与简介，没有读到正文」——**不伪造要点**。

实测（2026-10-31）：匿名 16 个样本 0 命中；带上 SESSDATA 后立刻拿到 AI 字幕。但字幕会骗人：同一场演讲重复取稿分别返回过 260 / 416 / 428 / 1476 段，也返回过 6 段 30 字、内容完全无关的片段。所以重复取稿时若新版更全且语速合理（≤600 字/分钟）会自动升级，id 不变。

## 和认知核心的关系

两个独立插件，零代码耦合。从认知核心 **0.24.0** 起，核心可以只读搜手账（设置里打开「读取学习手账」），回忆没有结果时会如实指出「学习管家里有」。桥不写本插件的数据，关掉即刻失效。

## 装

见包内 `INSTALL.md`：整目录放进 `resources/app/plugins/cognition-study`，`plugin.json` 必须在这一层；`config.trustedPlugins` 里加 `cognition-study`（要读写本地文件）；完全退出 QQ Agent 再启动。

## 边界

```text
只读 B站 公开信息     不登录账号做别的操作，不代发评论
不做向量检索          词面匹配 + 关键词；同义改写在核心侧借同义词表
修订不可删            只能追加修订，这是设计：留着「当时怎么写的」
额度是硬的            每天 2 篇 / 6000 字，超了明说超了
字幕质量不可控        B站 AI 字幕会返回不完整甚至无关内容，插件只能标注，不能辨真伪
```
